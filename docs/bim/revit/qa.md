# QA e Certificacao J43

Execute:

```text
node tests/revit-qa-certification.test.js
```

O harness cobre `CONNECT`, `READ`, `QUERY`, `QUANTIFY`, `IMPORT`, `VISUALIZE`, `COMMAND`, `SYNC`, `VALIDATE` e `RECOVER`.

`CERTIFIED` significa que o fluxo virtual/dedicado passou. A certificacao de escrita live exige um projeto Revit de teste dedicado e evidencias do Revit Desktop.
